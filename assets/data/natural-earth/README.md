# Natural Earth vector basemap

This directory contains the local vector layers used by `collaborators-map.html`:

- `ne_110m_land.geojson`
- `ne_110m_admin_0_boundary_lines_land.geojson`

Source: [Natural Earth Vector](https://github.com/nvkelso/natural-earth-vector), 1:110m scale.

Natural Earth data is in the public domain and is supported by the North American Cartographic Information Society (NACIS). The files were retrieved on 2026-10-31 and are served locally with the website; the published page does not request a third-party map or tile service at runtime.
